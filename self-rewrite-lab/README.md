## שלב 1 — איך זה עובד

ב-ion-loop המהנדס כתב מראש רשימת שינויים (`cycles.py`) על כפתורים שכבר קיימים בקוד. כאן אין רשימה: בכל דור המודל מקבל את קוד המדיניות הנוכחי, את הציונים ואת הכישלונות, ו**כותב קובץ חדש**.

1. **הגנום** (`rewrite/genome/seed.py`) — הקובץ היחיד שהלולאה רשאית לשנות. בתוכו: `CONFIG` (כפתורי הסוכן), `SYSTEM_EXTRA` (תוספת לפרומפט המערכת), `prepare(question, doc)` (שכתוב השאלה) ו-`finalize(question, answer)` (ניקוי התשובה). דור 0 הוא התצורה הזוכה של ion-loop מחזור 3.
2. **המציע** (`rewrite/proposer.py`) — כברירת מחדל זה אותו מודל שהסוכן מריץ, כלומר שכתוב עצמי ממש. הוא רואה את הגנום, את הציונים ב-dev ועד 6 כישלונות מהקטגוריה החלשה, וגם את הניסיונות האחרונים שנדחו ואת הסיבה. הוא **לא** רואה את הסט הנסתר. אפשר להפנות אותו לכל שרת תואם OpenAI.
3. **ארגז החול** (`rewrite/sandbox.py`) — בדיקה סטטית לפני שהקוד רץ: רק ייבוא של `re`, `math`, `json` ועוד כמה; בלי קבצים, רשת, תהליכים או רפלקציה; בלי `while`, `lambda` או שמות שמתחילים ב-`_`; מפתחות `CONFIG` מוכרים בלבד; טבלת builtins מצומצמת בזמן ריצה.
4. **השער** (`rewrite/gate.py`) — מריץ את הגנום על הארנה בתהליך נפרד עם מגבלת זמן. גנום מתקבל רק אם הציון הכולל עלה ואף קטגוריה לא ירדה ביותר מ-10 נקודות (אותו כלל כמו ב-ion-loop). טביעת אצבע של כל קובצי השופט (הבודק, הסטים, הסוכן, השער עצמו) נבדקת לפני כל החלטה, ושינוי בהם עוצר את הריצה.
5. **השושלת** (`rewrite/lineage/<model>/`) — `g000.py` (ה-seed), `gNNN.py` לכל דור שהתקבל, `attempts/` עם כל הצעה כפי שנכתבה, ו-`history.jsonl` עם הציון, ה-diff והסיבה להחלטה.

הסט הנסתר נמדד פעם אחת בסוף הריצה, ל-seed ולזוכה, ולא משמש לשום החלטה.

## הרצה

```bash
pip install "llama-cpp-python[server]" requests pyarrow pytest
python3 -m llama_cpp.server --model qwen2.5-1.5b-instruct-q4_k_m.gguf --n_ctx 8192 --port 8080 &
# אינדקס החיפוש (פעם אחת): parquet של 20231101.he מ-huggingface.co/datasets/wikimedia/wikipedia
(cd ion-loop && python3 -m ion.build_index <תיקיית parquet> data/hewiki.db)

python3 -m pytest -q rewrite/tests                         # 18 בדיקות, בלי מודל
python3 -m rewrite.evaluate --genome rewrite/genome/seed.py # ציון של גנום אחד
python3 -m rewrite.loop --generations 10                    # הלולאה
```

משתני סביבה: `ION_BASE_URL` ו-`ION_TAG` (הסוכן, כמו ב-ion-loop), ו-`REWRITE_PROPOSER_URL` ו-`REWRITE_PROPOSER_MODEL` (מציע אחר מהסוכן).
